# Matrizhammer

Calculadora de matrices para torneos por equipos de Warhammer 40.000 (Teams Event Companion v1.0).
Puntúas de 1 a 7 cada cruce de tu equipo contra el rival; la app calcula el defensor, los atacantes
y los rechazos óptimos paso a paso y prevé lo que elegirá el rival.

```bash
npm install
npm run dev
npm run test
```

Toda la arquitectura y las decisiones de diseño están en [CLAUDE.md](./CLAUDE.md).
